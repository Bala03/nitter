About {{.cfg.Title}}

A free and open source alternative Twitter front-end focused on privacy and performance.

Features

  • No JavaScript or ads
  • All requests go through the backend, client never talks to Twitter
  • Prevents Twitter from tracking your IP or JavaScript fingerprint
  • Uses Twitter's unofficial API (no rate limits or developer account required)
  • Lightweight pages
  • RSS feeds with full media information including:
    • Image attachments with original quality download links
    • Video attachments with direct MP4 download links (all quality options)
    • GIF attachments with direct download links
    • Sticker information
    • Media dimensions, duration, and bitrate metadata
    • Standard RSS enclosure and media:content elements for podcast/feed reader compatibility
  • Themes
  • Mobile support (responsive design)

RSS Feeds

RSS feeds are available for user timelines, media tabs, and search results:

  • /username/rss - User's timeline
  • /username/media/rss - User's media tweets
  • /username/with_replies/rss - User's tweets and replies
  • /search/rss?q=query - Search results

Each RSS item includes:

  • Full tweet text
  • Media type indicators (photo, video, GIF, sticker)
  • Direct download links for all media attachments
  • Video quality variants (multiple MP4 bitrates)
  • Media dimensions and duration metadata
  • RSS enclosures for feed reader media playback
  • media:content elements with full MRSS metadata
  • Quoted tweet content and media
  • Engagement stats (retweets, likes, replies)

Technology

Built with Go for high performance and low resource usage.

Source code: github.com/zedeus/nitter
