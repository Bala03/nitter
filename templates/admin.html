ℹ️ How it works

  • Login: Your Twitter username/password is used once to authenticate with Twitter's login flow.
  • Session tokens: The resulting auth_token and ct0 cookies are extracted and saved.
  • Storage: Sessions are stored in session.jsonl (one JSON object per line).
  • API requests: When active sessions exist, they are used (round-robin) for Twitter API requests instead of guest tokens.
  • Credentials: Your password is never stored — only the session cookies.
  • Expiry: Sessions may expire. Use the validate button (🔍) to check, or re-add the account.
